Privacy Policy – YT Manager

Last updated: November 21, 2026

1. What the app does

YT Manager is a desktop application that runs locally on the user's own computer. It lets channel owners manage their own YouTube channels: upload and schedule videos, edit titles, descriptions and tags, set thumbnails, manage playlists and view channel statistics.

2. Data we access

With the user's permission (Google OAuth 2.0), the app accesses the following through the YouTube Data API and YouTube Analytics API: channel information, the user's videos and playlists, video metadata, and channel statistics. The app only performs actions the user requests inside the app.

3. How data is stored

All data, including OAuth access tokens, is stored only on the user's own computer, in the app's local data folder. We do not operate any server that receives this data. We do not sell, share or transfer Google user data to any third party, and we do not use it for advertising.

If the user enables the optional AI writing feature, only the text the user enters (video topic and notes) is sent to the AI provider chosen by the user in order to generate titles and descriptions. No Google account data or tokens are sent.

4. Google API Services User Data Policy

YT Manager's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube features, users also agree to the YouTube Terms of Service and the Google Privacy Policy.

5. Revoking access and deleting data

Users can revoke the app's access at any time at https://myaccount.google.com/permissions. Removing a channel in the app deletes its stored token; deleting the app's data folder removes all locally stored data.

Tóm tắt tiếng Việt

YT Manager chạy trên máy tính của chủ kênh. Dữ liệu kênh và token đăng nhập chỉ lưu trên máy đó, không gửi về máy chủ nào, không bán hay chia sẻ cho bên thứ ba. Bạn có thể thu hồi quyền truy cập bất cứ lúc nào tại myaccount.google.com/permissions.
