YT Manager

YT Manager is a personal desktop tool that helps the owner manage their own YouTube channels: scheduling video uploads, writing titles, descriptions and tags, setting thumbnails, organizing playlists and reviewing channel statistics.

The app runs only on the owner's own computer (localhost). It uses the YouTube Data API and YouTube Analytics API with the channel owner's explicit permission via Google Sign-In (OAuth 2.0).

YT Manager là công cụ cá nhân chạy trên máy tính của chủ kênh, giúp quản lý các kênh YouTube của chính mình: lên lịch đăng video, viết tiêu đề/mô tả/tag, đặt thumbnail, sắp xếp playlist và xem thống kê.
